# TaskFlow - 产品需求文档（PRD）

## 一、产品概述

### 1.1 产品定位
TaskFlow 是一款面向 5-20 人小型创业团队的轻量级看板式任务管理工具，帮助产品团队和运营团队高效管理任务和项目进度。

### 1.2 核心价值
- **可视化工作流**：通过看板和拖拽直观展示任务状态
- **团队协作**：支持多人协作、权限管理和任务分配
- **轻量高效**：专注核心功能，降低学习成本

### 1.3 商业模式
- **免费版**：支持 5 人团队，基础功能
- **Pro 版**：¥29/人/月，无限成员 + 高级功能

---

## 二、目标用户

### 2.1 用户画像

| 角色 | 描述 | 核心痛点 |
|------|------|----------|
| 产品经理 | 管理产品开发任务，跟踪需求进度 | 需要快速创建和分配任务，可视化任务流转 |
| 运营人员 | 管理活动排期和营销任务 | 需要管理多个并行活动，设置截止日期提醒 |
| 团队负责人 | 管理团队成员和项目进度 | 需要权限管理、查看团队工作负载 |

### 2.2 核心场景
1. **产品团队**：管理开发任务，从需求收集到上线全流程跟踪
2. **运营团队**：管理活动排期，协调多人协作完成营销活动

## 三、功能模块

### 3.1 看板管理（P0）

#### 3.1.1 看板创建与配置
- 支持创建、编辑、删除看板
- 看板名称不超过 50 字符
- 支持看板描述（可选）

#### 3.1.2 列表管理
- 在看板中创建自定义列表（如：待办、进行中、已完成）
- 支持拖拽调整列表顺序
- 每个看板最多 10 个列表

#### 3.1.3 任务卡片 CRUD
- 任务包含：标题、描述、截止日期、优先级、标签
- 支持 Markdown 格式描述
- 支持任务复制和归档

#### 3.1.4 拖拽排序
- 拖拽操作流畅，响应时间 <300ms
- 支持移动端触摸拖拽
- 拖拽后自动保存位置

### 3.2 团队协作（P1）

#### 3.2.1 团队创建与管理
- 免费版最多 5 人，Pro 版无限制
- 支持邮箱邀请成员
- 支持移除成员

#### 3.2.2 权限管理
- **管理员**：所有权限
- **成员**：创建/编辑任务，不能删除看板
- **只读成员**：仅查看，不能编辑

#### 3.2.3 任务分配
- 支持单人和多人分配
- 被分配者收到通知
- 任务卡片显示负责人头像

### 3.3 标签与分类（P0）

#### 3.3.1 标签管理
- 支持自定义标签名称和颜色
- 每个任务可添加多个标签
- 支持按标签筛选任务

#### 3.3.2 优先级设置
- 优先级用颜色区分（高/中/低）
- 支持按优先级排序
- 高优先级任务突出显示

### 3.4 通知与提醒（P2）

#### 3.4.1 截止日期提醒
- 提前 1 天和 1 小时提醒
- 支持邮件和应用内通知
- 可自定义提醒时间

#### 3.4.2 活动通知
- 支持应用内通知中心
- 支持邮件通知（可配置）
- 通知可标记已读

### 3.5 评论与附件（P2）

#### 3.5.1 任务评论
- 支持 @ 提及团队成员
- 支持 Markdown 格式
- 评论可编辑和删除

#### 3.5.2 附件上传
- 支持图片、文档等常见格式
- 免费版单文件 5MB，Pro 版 20MB
- 支持拖拽上传

### 3.6 商业化功能（P1）

#### 3.6.1 订阅管理
- 支持支付宝/微信支付
- 按人/月计费，¥29/人/月
- 支持升级和降级

#### 3.6.2 功能限制
- **免费版**：5 人团队，基础功能
- **Pro 版**：无限成员，高级功能（附件、优先支持）

## 四、技术架构

### 4.1 技术栈

| 层级 | 技术选型 |
|------|----------|
| 前端框架 | React 18+ |
| UI 组件库 | Ant Design / Material-UI |
| 状态管理 | Redux Toolkit / Zustand |
| 后端框架 | Node.js + Express / NestJS |
| 数据库 | PostgreSQL 14+ |
| ORM | Prisma / TypeORM |
| 容器化 | Docker + Docker Compose |
| 云平台 | 阿里云 |

### 4.2 第三方服务
- **存储**：阿里云 OSS（附件存储）
- **邮件**：阿里云邮件推送服务
- **支付**：支付宝/微信支付 SDK

## 五、非功能需求

### 5.1 性能要求
- 页面首屏加载 < 2s
- API 响应时间 < 500ms（P95）
- 拖拽操作延迟 < 300ms

### 5.2 可扩展性
- 支持 1000 并发用户
- 支持单看板 1000+ 任务卡片

### 5.3 可用性
- 系统可用性 99.5% 以上
- 每日自动备份，保留 30 天

### 5.4 安全性
- JWT Token 认证 + HTTPS
- 基于角色的访问控制（RBAC）
- 敏感数据加密存储

# EARS 任务拆解

## 任务列表

### TASK-001 | 看板管理 | P1
**类型**：ubiquitous  
**描述**：系统应当允许用户创建、编辑和删除看板  
**角色**：fullstack  
**验收标准**：
- 用户可以创建新看板，输入名称和描述
- 用户可以编辑看板名称和描述
- 用户可以删除看板（需二次确认）
- 看板名称不超过 50 字符  
**依赖**：无

---

### TASK-002 | 看板管理 | P1

- 新建看板自动包含三个默认列表
- 列表顺序为：待办、进行中、已完成
- 用户可以修改默认列表名称  
**依赖**：TASK-001
