## 1. 撤回投标 (#88)

### `PUT /api/v1/bids/:bidId/withdraw`

**认证**：JWT Required

**路径参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| bidId | string | 投标 UUID |

**请求体**：无

**成功响应** `200`：
```json
{
  "code": 0,
  "message": "投标已撤回",
  "data": {
    "status": "withdrawn"
  },
  "request_id": "req_xxx"
}
```

**错误响应**：

| code | 说明 |
|------|------|
| 30001 | 投标不存在（或非本人投标） |
| 30003 | 投标已关闭或已处理（仅 pending 状态可撤回） |
| 11001 | 用户不存在 |

**业务规则**：
- 仅投标者本人可撤回
- 仅 status=1（pending）的投标可撤回，撤回后 status→4（withdrawn）
- 撤回后项目 bid_count 自动 -1

## 2. 作品集 CRUD (#89)

### `POST /api/v1/users/me/portfolios`

**认证**：JWT Required

**请求体**：
```json
{
  "title": "电商小程序",
  "description": "为某品牌开发的微信小程序",
  "category": "mini-program",
  "cover_url": "https://example.com/cover.jpg",
  "tech_stack": ["Flutter", "Go", "MySQL"]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | ✅ | 作品标题 |
| description | string | 否 | 作品描述 |
| category | string | 否 | 分类，默认 "other" |
| cover_url | string | 否 | 封面图 URL |
| tech_stack | string[] | 否 | 技术栈标签 |

**成功响应** `200`：
```json
{
  "code": 0,
  "message": "作品创建成功",
  "data": {
    "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "title": "电商小程序"
  },
  "request_id": "req_xxx"
}
```

```json
  "category": "web-app",
  "cover_url": "https://example.com/new-cover.jpg",
  "tech_stack": ["React", "Node.js"]

```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|

| description | string | 否 | 作品描述 |
| category | string | 否 | 分类 |
| cover_url | string | 否 | 封面图 URL |
| tech_stack | string[] | 否 | 技术栈标签 |

**成功响应** `200`：
```json
{
  "code": 0,
  "message": "作品更新成功",
  "data": {
    "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

## 3. 收藏功能 (#87)

### `POST /api/v1/favorites`

**认证**：JWT Required

**请求体**：
```json
{
  "target_type": "project",
  "target_id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| target_type | string | ✅ | `"project"` 或 `"expert"` |
| target_id | string | ✅ | 目标的 UUID |

**成功响应** `200`：
```json
{
  "code": 0,
  "message": "收藏成功",
  "data": {
    "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  },
  "request_id": "req_xxx"
}
```

**业务规则**：
- **幂等**：重复收藏返回成功 + 已有记录的 UUID，不报错
- target_type=project 时自动更新项目 favorite_count +1
- target_type=project 时会校验项目是否存在

**错误响应**：

| code | 说明 |
|------|------|
| 99001 | target_type 不支持 |
| 20001 | 项目不存在（target_type=project 时） |

---

### `GET /api/v1/users/me/favorites`

**认证**：JWT Required

**Query 参数**：

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| page | int | 否 | 1 | 页码 |
| page_size | int | 否 | 20 | 每页条数（最大 50） |
| target_type | string | 否 | 全部 | 筛选类型：`"project"` / `"expert"` |

**成功响应** `200`：
```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": "fav-uuid",
      "target_type": "project",
      "target_id": "project-uuid",
      "created_at": "2026-04-04T12:00:00Z",
      "title": "电商小程序开发",
      "status": 2,
      "category": "mini-program",
      "budget_min": 5000,
      "budget_max": 10000
    },
    {
      "id": "fav-uuid-2",
      "target_type": "expert",
      "target_id": "user-uuid",
      "created_at": "2026-04-03T10:00:00Z",
      "nickname": "张三",
      "avatar_url": "https://example.com/avatar.jpg",
      "rating": 4.8
    }
  ],
  "meta": {
    "page": 1,
    "page_size": 20,
    "total": 2,
    "total_pages": 1
  },
  "request_id": "req_xxx"
}
```

**响应字段说明**：

基础字段（所有类型都有）：

| 字段 | 说明 |
|------|------|
| id | 收藏记录 UUID |
| target_type | project / expert |
| target_id | 目标 UUID |
| created_at | 收藏时间 |

target_type=project 时附加：

| 字段 | 说明 |
|------|------|
| title | 项目标题 |
| status | 项目状态 |
| category | 项目分类 |
| budget_min | 预算下限 |
| budget_max | 预算上限 |

target_type=expert 时附加：

| 字段 | 说明 |
|------|------|
| nickname | 专家昵称 |
| avatar_url | 头像 |
| rating | 评分 |
